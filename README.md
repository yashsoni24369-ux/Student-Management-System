# Student Management System

A Python-based Student Management System that allows users to manage student records through a simple command-line interface.

## Features

* Add student
* Display all students
* Search student by ID
* Search student by name
* Update student information
* Delete student
* Count total students
* Find top student
* Find lowest student
* Sort students by average marks
* Calculate total marks
* Calculate average marks
* Automatically assign grades
* Calculate pass/fail status
* Store student data using JSON

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* JSON
* Git
* GitHub

## Student Information

The system stores:

* Student ID
* Student name
* Student age
* Marks for 5 subjects
* Total marks
* Average marks
* Grade
* Pass/Fail status

## How to Run

Make sure Python is installed on your computer.

Open the project folder in Command Prompt or VS Code terminal.

Run:

```bash
python main.py
```

The Student Management System menu will appear.

